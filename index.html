TEKS SNS Publisher

교회 청년부 설교 영상(쇼츠)을 관리자 본인의 유튜브 채널 교회청년 Church youth와 인스타그램 계정에 정해진 시간에 올리기 위해 관리자가 직접 만든 개인용 프로그램입니다.

  • 관리자 한 사람만 자기 PC에서 사용합니다. 일반 사용자의 가입·로그인·데이터를 받지 않습니다.
  • YouTube API 서비스를 사용해 관리자 본인 채널에 영상을 올리고, 올린 영상의 주소와 공개 상태를 확인합니다.
  • 로그인 정보(토큰)는 관리자 PC 안에만 저장되며 외부 서버로 보내지 않습니다.

개인정보처리방침 (Privacy Policy)

English

TEKS SNS Publisher is a personal tool built and used by a single administrator to schedule uploads of short sermon videos to the administrator's own YouTube channel (교회청년 Church youth) and Instagram account. It does not offer sign-up or login to anyone else and does not collect data from other users. It uses YouTube API Services only to upload videos to the administrator's own channel and to check each uploaded video's URL and privacy status. Credentials are stored only on the administrator's PC.
