TEKS SNS Publisher 개인정보처리방침

시행일: 2026-10-29

1. 이 앱이 무엇인가

TEKS SNS Publisher는 관리자 한 사람이 자기 PC에서 쓰는 개인용 게시 프로그램입니다. 관리자 본인의 유튜브 채널에 관리자가 만든 영상을 올리는 데만 쓰며, 다른 사람에게 서비스를 제공하지 않습니다.

2. 사용하는 Google 데이터

  • youtube.upload: 관리자 본인 채널에 영상을 올립니다.
  • youtube.readonly: 로그인한 채널 이름이 맞는지, 같은 영상이 이미 올라가 있는지, 올린 영상의 공개 상태가 무엇인지 확인합니다.

이 앱은 YouTube API 서비스를 사용합니다. 이 앱을 쓰는 것은 YouTube 서비스 약관에 동의하는 것이며, Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

3. 저장과 공유

  • Google 로그인 정보(OAuth 토큰)는 관리자 PC의 Windows 자격 증명 관리자에만 저장합니다.
  • 올린 영상의 주소와 공개 상태는 관리자의 게시 기록 파일에만 남깁니다.
  • 어떤 데이터도 외부 서버로 보내거나 다른 사람·회사에 판매·공유하지 않습니다. 광고에 쓰지 않습니다.
  • 관리자 외 다른 사람의 개인정보를 수집하지 않습니다.

TEKS SNS Publisher가 Google API로부터 받은 정보를 사용하고 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

4. 연결 해제와 삭제

Google 계정 → 보안 → 타사 앱 및 서비스(myaccount.google.com/connections)에서 언제든 이 앱의 액세스를 해제할 수 있습니다. 해제하면 저장된 토큰은 더 이상 쓸 수 없고, 관리자 PC에서도 지웁니다.

Privacy Policy (English)

Effective: 2026-10-29

TEKS SNS Publisher is a personal tool used by a single administrator on their own PC to upload the administrator's own videos to the administrator's own YouTube channel. It does not provide a service to anyone else.

Google data used. youtube.upload to upload videos to the administrator's channel; youtube.readonly to confirm the signed-in channel name, check for duplicates among recent uploads, and read the privacy status of uploaded videos. This app uses YouTube API Services; by using it you agree to the YouTube Terms of Service, and Google's handling of data is governed by the Google Privacy Policy.

Storage and sharing. OAuth tokens are stored only in Windows Credential Manager on the administrator's PC. Video URLs and privacy status are kept only in the administrator's local posting log. No data is sent to any external server, sold, shared with third parties, or used for advertising. No personal data of anyone other than the administrator is collected.

TEKS SNS Publisher's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at myaccount.google.com/connections; the administrator then deletes the stored tokens from the PC.
